# 🏫 CampusEase – Role-Based Complaint Management System

## 📌 Project Description

CampusEase is a centralized complaint management system designed to streamline the process of submitting, tracking, and resolving complaints within an institution. It improves efficiency and transparency by allowing users to raise issues and monitor their status in real-time.

---

## 🚀 Features

* Role-based access (Admin,Student)
* Secure authentication using JWT
* Complaint submission and tracking
* Status updates (Pending → In Progress → Resolved)
* Organized dashboard for managing complaints

---

## 🛠️ Tech Stack

## 🔄 Workflow

1. User logs in based on role
2. User submits complaint
3. Admin reviews complaint
4. Status is updated
5. User tracks complaint progress

---

## ▶️ How to Run

### Backend (Spring Boot)

```
mvn spring-boot:run
```

### Frontend (Angular)

```
npm install
ng serve
```
